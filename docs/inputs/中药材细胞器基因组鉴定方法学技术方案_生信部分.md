# 中药材细胞器基因组鉴定方法学技术方案（生物信息学部分）

**版本**：v1.0 ｜ **日期**：2026-08-07 ｜ **状态**：流程框架已收敛，标注【待验证】的环节须经第 8 章前置实验确认后方可写入 SOP

---

## 0. 文档说明与使用方式

1. 本方案的生信流程**不按样本来源分层**（不区分凭证标本/检品/炮制品），仅按**数据可得性**分为三条主线：
   - **场景 A：仅有二代数据**（DNBSEQ 短读长）
   - **场景 B：仅有三代数据**（CycloneSEQ 长读长）
   - **场景 C：同时拥有二代+三代数据**
2. 三条场景共用同一套**判定层**（第 6 章）与**工具准入制度**（第 7 章）。
3. 样本能否进入某条流程，由实验端提供的 DNA 完整性信息决定（本方案不规定采样与前处理）；生信端只要求随数据附带两个元数据字段：DNA 片段分布（主带/N50，如有）与提取批次号。
4. 文档中所有工具的功能声明均经官方文档核验（核验日期 2026-08-07）；维护状态来自 GitHub 仓库实测提交记录。

## 1. 总则

### 1.1 核心原则（不可妥协的四条底线）

| # | 原则 | 含义 |
|---|---|---|
| P1 | **判定锚定二代证据** | 作为鉴定判定依据的最终序列，其可判定区域必须有 DNBSEQ 短读长证据支持；纯三代序列不得单独作为判定终序列（原因见 4.1） |
| P2 | **三层工具准入制** | 工具按"对平台的假设强度"分准入层/参数条件层/禁入层（第 7 章）；候选资格可按原理给，SOP 准入只能按实测给 |
| P3 | **不预设未经验证的数值** | 测序数据量、Q 值过滤阈值、抛光工具选择等，一律通过第 8 章前置实验标定，文档中不写死 |
| P4 | **诚实的不确定输出** | 证据不足的位点保留 N 或标记不确定，不强行生成确定碱基；证据不足的样本输出"无法判定"，不强行归属 |

### 1.2 方法学定位

- 植物类药材：以**完整叶绿体基因组（超级条形码）+ nrDNA（含 ITS2）**为鉴定依据；植物线粒体为研究级证据，不进常规判定（原因见 4.4）。
- 动物类药材：以**完整线粒体基因组 + ITS2 辅助**为鉴定依据。
- 细胞器基因组**不是绝对物种身份证**：杂交、叶绿体捕获、不完全谱系分选（ILS）、MTPT/NUPT/NUMT 均可导致错误归属。近缘复杂类群必须加入独立核基因证据（6.3）。

### 1.3 术语与缩写

| 缩写 | 含义 |
|---|---|
| skimming | 全基因组浅层测序（核基因组覆盖度 <1× 的 shotgun 测序） |
| IR / LSC / SSC | 叶绿体反向重复区 / 大单拷贝区 / 小单拷贝区 |
| nrDNA | 核糖体 DNA 串联重复阵列（45S，含 18S–ITS1–5.8S–ITS2–26S） |
| NUMT / NUPT / MTPT | 核内线粒体假基因 / 核内叶绿体假基因 / 线粒体内叶绿体转移片段 |
| HMW | 高分子量（DNA） |
| GFA | 组装图文件格式（Graphical Fragment Assembly） |

## 2. 公共层：数据质控与预检

无论何种数据组合，所有样本先经本章处理。

### 2.1 二代数据质控

- **工具**：fastp（GitHub 2410 stars，最近提交 2026-07-30，极活跃）。
- **参考参数**：
  ```bash
  fastp -i R1.fq.gz -I R2.fq.gz -o clean_R1.fq.gz -O clean_R2.fq.gz \
        --detect_adapter_for_pe --qualified_quality_phred 15 \
        --length_required 50 --html sample.fastp.html --json sample.fastp.json
  ```
- **验收节点 Q1**：Q30 ≥ 85%；clean reads ≥ 合同数据量；接头残留 < 0.1%；duplication 异常高（>60%）时记录并提示建库问题。
- **记录**：fastp 的 HTML/JSON 报告随样本归档。

### 2.2 三代数据质控

- **工具**：NanoPlot（最近提交 2026-08-03，极活跃）。
  ```bash
  NanoPlot --fastq cyclone.fastq.gz --outdir nanoplot_out --threads 16
  ```
- **必出指标**：reads 总数、总碱基数、read N50、Q 值分布曲线。
- **过滤**【待验证阈值】：用 filtlong/chopper 按长度与质量过滤；**Q 值阈值不照搬 ONT 经验值**——CycloneSEQ 的 Q 值标定与 ONT 未必一致，须按第 8.1 节实测质量分布标定后确定。
- **验收节点 Q2**：过滤后 read N50 达到后续流程的档位要求（见各场景）；Q 值分布曲线归档。

### 2.3 污染/掺伪预检（仅预检，不作判定证据）

- **工具**：Kraken2（926 stars，最近提交 2026-07-29，极活跃）。
- **数据库**：**必须自建**——由自建正品/伪品参考库 + 常见真菌 + 环境污染物整理而成；**严禁使用通用 Kraken 公共库作为中药真伪判定依据**。
- **输出定位**：仅作为"快速预警层"——检出非预期物种 reads 比例异常时触发人工复核；预检结果不写入判定结论。

### 2.4 公共层质控节点一览

| 节点 | 内容 | 不通过处置 |
|---|---|---|
| Q1 | 二代 fastp 质量基线 | 重测或降级为"仅参考引导比对" |
| Q2 | 三代 NanoPlot + 过滤后 N50 | 按场景 B/C 的档位规则分流或仅走场景 A |
| Q3 | Kraken2 预检无异常预警 | 触发人工复核，必要时启动掺伪排查（6.4） |

## 3. 场景 A：仅二代数据流程

**适用判定**：样本只有 DNBSEQ 数据。这是成本最低、判定精度最高的常规路径。

### 3.1 植物：叶绿体组装（主流程）

- **首选**：GetOrganelle（391 stars，2025-02 维护中；文献 Jin et al. 2020 *Genome Biology*，被引约 4000）。
  ```bash
  get_organelle_from_reads.py -1 clean_R1.fq.gz -2 clean_R2.fq.gz \
      -o chloroplast_out -R 15 -k 21,45,65,85,105 -F embplant_pt
  ```
- **互验**：NOVOPlasty（198 stars，2024-02 低维护但算法成熟稳定）独立组装；两者结果一致方可进入注释，不一致时用 Bandage 人工查看组装图仲裁。
- **基准依据**：系统比较研究（Freudenthal et al. 2020）显示 GetOrganelle 在完整性与准确性上综合最优。
- **产出**：环化叶绿体全序列（目标 ~120–170 kb，视类群）；未环化时输出 scaffold 并标注"草稿级"。

### 3.2 植物：nrDNA/ITS2 提取与杂合度检查

- 同一 GetOrganelle 运行追加 nrDNA 模式：
  ```bash
  get_organelle_from_reads.py -1 clean_R1.fq.gz -2 clean_R2.fq.gz \
      -o nrdna_out -k 35,85,115 -F embplant_nr
  ```
- **产出**：45S 重复单元一致性序列（约 5.8 kb，含 ITS2）。**注意**：完整串联阵列（数百至数千拷贝）不可组装，本流程以一致性单元为准——这正是药典 9107 体系使用的层级。
- **杂合度检查**：统计 ITS2 区 reads 的个体内多态性；杂合 reads 比例超过【待验证阈值】时标注"疑似杂交来源"，判定时叶绿体与核证据分别报告（6.3.1）。

### 3.3 动物：线粒体组装

- **首选**：MitoFinder（116 stars，2025-09 活跃；Allio et al. 2020 *Mol. Ecol. Resour.*）——从 clean reads 直接组装 + 注释 + 基因排序标准化，批量友好。
- **备选**：MitoZ（149 stars，2024-11 低频维护；Meng et al. 2019 *NAR*）——组装+注释+可视化一体包。
- **NUMT 排检**（强制）：组装结果回贴 reads，排除以下特征序列——异常低覆盖、带核基因组侧翼序列、蛋白编码基因出现提前终止密码子或移码。

### 3.4 注释

- 叶绿体：**PlastidHub**（2025-06 维护中的在线整合平台，注释+比较基因组+IR 分析）；备选 GeSeq（机构在线服务）。
- 动物线粒体：MitoFinder/MitoZ 自带注释；独立复核用 MITOS2（在线服务）。
- IR 边界可视化：IRscope（在线工具）。

### 3.5 组装质控（强制三件套）

1. **Bandage 看图**（672 stars，2026-07 活跃）：确认环化、无异常分支、无未解析重复泡；
2. **回贴验证**：clean reads 用 minimap2 回贴组装序列，检查覆盖度均一性；**出现覆盖洼地（局部深度 < 全序列中位数的 1/5）时，该区域标注为草稿级，不参与鉴别位点挖掘**；
3. **IR 边界核对**：两拷贝 IR 序列一致性检查；IR/单拷贝区交界位置与近缘参考比对。

### 3.6 低覆盖样本处置（重要）

- 数据量不足或降解样本上**禁止强行环化**。
- 降级路径：clean reads 直接比对自建参考库（minimap2 `-x sr`），转入判定层 6.1 的"参考引导判定"模式——以诊断位点覆盖与一致性为证据，不产出完整基因组。
- 该路径的输出结论与完整组装路径**具有同等判定效力**，但报告中须注明证据类型（完整基因组 vs 诊断位点比对）。

### 3.7 场景 A 流程图

```
fastp(Q1) → Kraken2 预检(Q3)
   ├─ 植物 → GetOrganelle(叶绿体+nrDNA) → NOVOPlasty 互验 → 注释
   ├─ 动物 → MitoFinder(或 MitoZ) → NUMT 排检 → 注释
   └─ 低覆盖 → minimap2 比对参考库（降级路径）
→ Bandage + 回贴 + IR 边界（质控三件套）
→ 判定层（第 6 章）
```

## 4. 场景 B：仅三代数据流程

**适用判定**：样本只有 CycloneSEQ 数据。**本场景产出的序列默认不直接作为判定终序列**（原则 P1），其定位是：结构解析、参考库候选骨架、无近缘参考时的探索性组装。

### 4.1 平台特性与风险前提（本场景所有决策的依据）

| 特性 | 数值/表现 | 生信后果 |
|---|---|---|
| 原始准确率 | 独立基准（6 种细菌）：均值约 96.0%、众数约 97.7%（Q14–Q16），与 ONT R10 常规档相当；**尚未见植物/叶绿体专项实测** | 禁止外推准确率；工具转移验证（8.1）必须先行 |
| 同聚物区 | 同聚物区准确率显著低于全局（基准中 G/C 同聚物约 79%）；错误为系统性、非随机 | **深度叠加不能消除系统性偏差**；同聚物/A-T 富集区（如 trnH-psbA）的碱基判定必须留待二代验证或人工标注 |
| "40× → Q40" | 厂商标称的平台级平均指标 | 只能作为全局参考，**不等于鉴定关键区达标**，不得作为方法学验收值 |
| 读长 | N50 约 30–40 kb（实测以 NanoPlot 为准）；最长 reads 的准确率沿长度分布暂无 CycloneSEQ 独立数据 | 建库以**片段 N50**为验收指标；绘制 read length–identity 关系列入转移验证 |
| Q 值标定 | 与 ONT 未必一致 | 过滤阈值按实测分布标定（2.2） |

### 4.2 植物：叶绿体（+可选植物线粒体）

- **首选**：PMAT2（官方 README 已核实：支持动/植/真菌，`-x/--taxo` 0=植物、1=动物、2=真菌；支持 `-t ont` 模式，内部调用 Canu/NextDenovo 纠错；官方示例数据量仅约 216–550 Mb；最近提交 2026-05，活跃）：
  ```bash
  PMAT autoMito -i filtered.fastq.gz -o pmat2_out -t ont -x 0 \
      -S nextdenovo -C canu -N nextdenovo
  ```
  【待验证】"支持 ONT"≠"已验证 CycloneSEQ"，须过 8.1 转移验证后准入 SOP。
- **独立复核路线**：minimap2（`-x map-ont` 作起点预设）比对到多近缘参考提取细胞器 reads → Flye 子集组装（**按 `--nano-raw` 档而非 hq 档**，CycloneSEQ 原始准确率不适用 hq 预设）→ 两路线结构一致方可接受。
- **Oatk 不适用**：Oatk 为 HiFi 数据设计，不属于"ONT 支持工具"，本场景禁入。

### 4.3 动物：线粒体

- **主路线**（平台无关，最稳健）：
  1. **多近缘参考 + 保守蛋白编码基因双重诱饵**提取候选线粒体 reads（minimap2；单一参考可能漏掉高度分化的控制区 D-loop——而 D-loop 恰是动物药鉴定高变区）；
  2. Flye 对提取子集组装（raw 档）；
  3. MitoFinder 识别、注释；
  4. **NUMT 复核**（同 3.3 标准）。
- **并行验证路线**：PMAT2 `-t ont -x 1`（animal mode 官方存在，但无 CycloneSEQ 专项验证）——仅作并行比较，验证通过前不写入 SOP 主流程。
- **MitoHiFi 禁入本场景**：官方以 PacBio HiFi reads 为原始输入，不是已验证的 CycloneSEQ 原始 reads 组装器。
- **禁止 Flye 直接全组装后捞线粒体**：全基因组 skimming 数据中线粒体覆盖极低，全组装既低效又有丢失风险；必须先提取子集。

### 4.4 植物线粒体（研究级，不进常规判定）

- 植物线粒体大而多重复、常呈多染色体结构，是本方案中唯一"非三代不可"的对象。
- 路线：PMAT2 `-t ont -x 0`（autoMito）；产物用于疑难基原解析与结构研究，**不作为常规鉴定判定依据**。
- 数据量需求远高于叶绿体（细胞器占比低），按 8.2 下采样曲线实测确定，不预设固定 Gb。

### 4.5 纯三代抛光与一致性

- **候选**：Racon（比对法抛光，不绑定碱基判读模型；2021 年后停更但算法成熟、至今是主流流程内嵌组件）迭代 1–2 轮 + 高深度一致性。
- **禁入**：medaka（模型绑定 ONT 化学版本/basecaller，无 CycloneSEQ 验证模型；注意 medaka 推理只需 basecalled FASTQ，问题是模型错配而非输入格式）、Nanopolish（依赖 ONT fast5 原始信号，物理不可用）、Clair3 的 ONT 预训练模型。
- **强制标注**：纯三代序列的同聚物区（≥6 bp 均聚物）与 A-T 富集区间在输出文件中逐位点标记"未经二代验证"。

### 4.6 场景 B 输出定位

| 产出 | 可用作 |
|---|---|
| 完整结构骨架（含 IR/环化证据） | 参考库候选序列（待场景 C 补齐二代证据后转正）；结构变异分析 |
| 序列一致性（全局） | 探索性比对、预检 |
| 同聚物/A-T 区碱基 | **不可**用于判定；报告与归档中保留标记 |

## 5. 场景 C：二代+三代混合数据流程（参考级序列生产）

**适用判定**：同一样本同时有两代数据。**这是参考库建设与疑难样本终裁的标准路径**，产出"参考级"序列。

### 5.1 总体策略

> **三代解决结构，二代解决精度**：CycloneSEQ 提供跨越 IR/重复区/环化连接的长程证据，DNBSEQ 提供每个可判定碱基的精度证据。混合组装（三代骨架+二代抛光）已有公开实证优于任何单一平台。

### 5.2 流程详述

```
NanoPlot/fastp(Q1/Q2) → Kraken2 预检(Q3)
→ 三代骨架：植物 PMAT2(-t ont -x 0)／动物 参考引导提取+Flye子集
   （并行独立路线复核结构：两路线结构一致才接受）
→ 二代抛光【两候选并行，首轮对照实验定终选】：
   路线 P1：Polypolish（paired-end 全比对含多重比对，重复区抛光可靠；
            插入长度 <200 bp 的小插入文库其核心优势失效，弃用该路线）
   路线 P2：严格变异调用—共识（minimap2/bwa 回贴 → bcftools call
            → 按深度/质量/等位基因比例硬过滤 → consensus）
→ 验收（5.4）→ 归档（5.5）→ 判定层
```

- **NextPolish2 移出首版主流程**：其标准输入面向 HiFi 组装的 k-mer 抛光，对 CycloneSEQ 骨架的适用性无公开验证；"同属华大生态"不构成技术依据。待验证后再议。
- **禁止**以 medaka 等模型绑定工具替代二代抛光（见 4.5）。

### 5.3 抛光质控要求

- 所有碱基修改**留痕**：修改前后序列、支持 reads 数、深度、等位基因比例、过滤原因，逐位点记录归档。
- 抛光完成后二代 reads 回贴终序列：统计未解释矛盾位点；矛盾位点 >【待验证阈值】时整序列降级为草稿。

### 5.4 验收标准（分区域证据标准）

| 区域类型 | 验收要求 |
|---|---|
| 单拷贝可判定区 | 达到预设的 DNBSEQ 双向覆盖、碱基质量、等位基因比例要求【阈值待 8.3 标定】 |
| IR 及多重比对区 | **单独评估**——短读长天然无法唯一比对，不设唯一覆盖硬指标；以配对端约束 + 长 reads 跨越证据为准 |
| 环化连接、IR/SC 交界 | 多条独立长 reads 跨越（≥3 条，且来自不同文库分子） |
| 证据不足位点 | **保留 N 或标记不确定，不强行生成确定碱基** |
| 整体 | Bandage 图无未解析异常；两独立路线结构一致 |

> 注意：**"零 indel"不是验收指标**——真实种间/个体内本就存在 indel；验收的对象是"每个确定碱基都有证据"，不是"与参考无差异"。

### 5.5 归档规范（参考级序列的强制归档清单）

| 类别 | 内容 |
|---|---|
| 原始数据 | 二代 clean reads、三代过滤后 reads 的存储位置与校验码 |
| 组装中间体 | **未简化 GFA 图**、候选结构异构体、两独立路线的各自结果 |
| 结构证据 | 跨越 IR/重复区/环化连接的长 reads 清单（read ID + 比对坐标） |
| 碱基证据 | 二代回贴 BAM、等位基因比例表、全部抛光修改留痕 |
| 风险标记 | NUMT/NUPT/MTPT 筛查结果、异质性（heteroplasmy）位点、ITS2 杂合度 |
| 元数据 | 样本编号、提取批次、DNA 片段分布、测序批次、软件版本与参数全记录 |

## 6. 判定层（三场景共用）

### 6.1 多证据判定框架

判定**不采用单一的"全长距离阈值"**，而是四要素组合：

1. **诊断位点**：与自建参考库比对后，正品与候选伪品间的固定差异位点（SNP/indel）检出情况；
2. **参考覆盖**：样本序列对参考基因组的覆盖广度与深度（防止"局部相似即判真"）；
3. **系统发育/似然定位**：全长（或可获得的最长共有区）ML 树定位，报告 bootstrap；
4. **不确定区**：当证据落在预设灰区（如与两个分类单元的距离差 < 阈值）时，强制输出"无法判定"。

### 6.2 判定输出类别

| 输出 | 定义 |
|---|---|
| 正品 | 四要素一致指向法定基原 |
| 非正品 | 四要素一致指向非基原（报告指向的具体分类单元） |
| 无法判定 | 证据不足或落入不确定区（报告中说明缺什么证据） |

### 6.3 复杂情形处理

**6.3.1 疑似杂交**：ITS2 杂合度超阈（3.2）时，叶绿体（母系遗传）与核证据**分别报告**，不做单一归属结论；必要时建议实验端加测单拷贝核基因标记。

**6.3.2 叶绿体捕获 / ILS / 近缘未分化类群**：叶绿体信号与已知分类冲突时，强制加入核基因证据层；判定结论注明"细胞器证据"与"核证据"各自指向。

**6.3.3 NUMT/NUPT/MTPT**：组装与判定全程执行假基因筛查（覆盖异常、核侧翼、提前终止）；发现 MTPT 时该区段不参与距离计算（已有药用植物因 MTPT 导致误鉴定的公开案例）。

### 6.4 掺伪的检出与定量边界

- **检出**：skimming 数据中出现两套细胞器信号（异常的双峰覆盖/双套单倍型）或 Kraken2 预检异常 → 报告"检出非基原信号"。
- **定量**：**reads 比例不能直接换算掺伪质量比例**（不同药用部位叶绿体含量、DNA 提取效率、降解程度差异大）。掺伪比例定量属靶向方法范畴（物种特异性 qPCR/dPCR），不在本方案生信流程内，但报告应建议实验端补做。

## 8. 前置验证实验（写入 SOP 前的强制环节）

### 8.1 工具转移验证（把"按理兼容"变成"本项目验证兼容"）

- **样本**：2–3 个有已知权威参考序列的样本（模式植物或已发表完整叶绿体/线粒体的基原）；
- **设计**：同一 DNA 分两份，CycloneSEQ 与可获得的 ONT/公共 ONT 数据对照，过同一条准入层/参数条件层工具链；
- **终点**：组装完整性、与参考的一致性、**分区域错误谱**（重点：matK、trnH-psbA 等 A-T 富集/同聚物区）、read length–identity 关系、实测 Q 值分布；
- **通过标准**：错误谱与 ONT 同量级且区域分布可解释 → 准入层工具整体转正。

### 8.2 下采样曲线（确定最低有效数据量，不预设固定 Gb）

- 对每类典型样本（植物叶/根茎类、动物组织），对三代数据做梯度下采样（如 0.2/0.5/1/2/5 Gb…），二代同理；
- 绘制"数据量–组装完整性/判定正确率"曲线，取拐点为 SOP 最低数据量；
- 叶绿体预期远低于植物线粒体；**两类对象分别标定**。

### 8.3 增益评估试点（Phase 0–3，项目科学责任所在）

- **Phase 0 困难组合筛选**：5–10 组"正品–近缘基原–常见伪品"组合；主标准：**基于法定条形码（ITS2/psbA-trnH/COI）的盲法种级鉴定正确率 < 95%**（辅助：单系性 bootstrap < 70% 或种间距离落入种内变异范围）；
- **Phase 1 参考级建库**：每分类单元 ≥3 个独立来源个体（**发现阶段最低配置**，不代表已覆盖种内变异；正式库按地理群体扩样），全部走场景 C 流程；部分物种加做鲜样/自然干燥/炮制降解梯度；涉及复方前景时加已知比例混合物与阴性提取/建库对照；
- **Phase 2 三路线盲法对比**：纯二代 vs 纯三代 vs 2+3 混合；**独立盲样验证集**；终点指标——盲样正确率、假阳性率、**无法判定率**；是否发现纯二代无法获得且经独立 PCR/Sanger 正交验证的诊断位点；关键结构连接是否有多条独立长 reads 跨越；单样本数据量/人工/失败率/成本；
- **Phase 3 Go/No-Go 决策**（预定义实际决策阈值，小样本试点不套"统计学显著"）：
  1. 是否发现并正交验证了纯二代无法获得的诊断位点；
  2. 是否解决至少一个原无法判定的困难组合；
  3. 是否降低错误判定或无法判定比例；
  4. 是否获得可靠的长程结构连接；
  5. 单样本失败率、人工时间和成本是否可接受。
  **未达阈值 → 三代降级为研究性证据层，不进鉴定 SOP。**

## 9. 局限性声明（须在对外方法学文件中原文保留）

1. 纯三代（CycloneSEQ）序列的同聚物/A-T 富集区存在系统性错误风险，未经二代验证前不作判定依据；
2. 降解不均样本的组装可能出现覆盖度洼地，洼地区域碱基判定证据不足，强制标注为草稿级；
3. 细胞器基因组为单亲遗传，杂交、叶绿体捕获、ILS 可致错误归属；复杂类群以核基因证据补充；
4. 本方法检出掺伪但不定量掺伪比例；定量属靶向方法（qPCR/dPCR）范畴；
5. 深度炮制/提取类样品中 DNA 阴性不能推定原料不存在，须结合化学标志物；
6. 植物线粒体路线为研究级，不进常规判定；
7. adaptive sampling（在线富集）为待厂商 API 确认的探索项，不在本方案内；"随测随停"节省的是机时与分析等待时间，不节省芯片耗材成本。
